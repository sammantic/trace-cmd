# tracegen

A small C program that records boot-stage messages ("barebox started",
"kernel loaded", ...) and writes them as a `trace.dat` file in trace-cmd v6
format, readable by `trace-cmd report` and KernelShark.

The file is generated by hand, without libtraceevent or libtracefs. The
recorder/writer (`trace.c`, `trace.h`) is separate from the demo (`main.c`) so
it can be reused elsewhere, for example inside barebox.

## Build and run

Requires a C11 compiler and make on a 64-bit little-endian Linux host.

```sh
make
./tracegen                  # writes trace.dat; use -o <file> for another path
trace-cmd report trace.dat
```

The demo plays a fixed, made-up barebox boot sequence, sleeping a few
milliseconds between stages:

```
cpus=1
         barebox-1     [000]  3385.270156: task:                 barebox started
         barebox-1     [000]  3385.282228: task:                 board init done
         barebox-1     [000]  3385.285287: task:                 console ready
         barebox-1     [000]  3385.325379: task:                 mounting boot fs
         barebox-1     [000]  3385.333449: task:                 loading kernel
         barebox-1     [000]  3385.483615: task:                 kernel loaded
         barebox-1     [000]  3385.489702: task:                 loading device tree
         barebox-1     [000]  3385.514862: task:                 booting kernel
```

## Using the recorder in your own code

Compile `trace.c` into your program and include `trace.h`:

```c
#include "trace.h"

trace_add("barebox started");
/* ... do work ... */
trace_add("kernel loaded");
trace_write("trace.dat");
trace_free();
```

| Function | What it does |
|----------|--------------|
| `trace_add(task)` | Append a message timestamped now (`CLOCK_MONOTONIC`). |
| `trace_add_at(ts_ns, task)` | Append a message with an explicit timestamp in nanoseconds. |
| `trace_write(path)` | Write all recorded messages to `path` as a trace.dat v6 file. |
| `trace_free()` | Release all recorded messages. |
| `trace_count()` | Number of messages currently recorded. |

Functions that can fail return 0 on success and -1 with `errno` set.
Messages are kept in memory until `trace_write` is called, and an empty list
still produces a valid file with no events.

## Tests

```sh
make test     # unit tests for the recorder and the page encoding
make check    # runs tracegen and verifies the output with trace-cmd report
```

`make check` needs `trace-cmd` installed.

## Limitations

- Only the trace-cmd v6 format is written; there is no v7 or compression.
- One CPU, and one event type (`barebox:task`, a single string).
- 64-bit little-endian hosts only, since integers are written in host byte order.
- The recorder keeps one global list and is not thread-safe.
- A single message is limited to roughly 4 KB, the size of one ring-buffer page.
